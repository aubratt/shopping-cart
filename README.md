# Shopping Cart

A mock e-commerce website with account creation/authentication through
[Firebase](https://firebase.google.com/). Feel free to create an account with
dummy info and "purchase" products to test out all the features. No real
payments are processed, and no credit card info is collected. Product
information is fetched from the [Fake Store API](https://fakestoreapi.com/).
